Method
1. Forward service/tak-server ports 8443 and 8089 to local ports 18443 and 18089.
2. Load test credentials from the dedicated tak-sim-* Secrets.
3. Validate the server certificate chain and hostname tak.localtest.me.
4. Patch User.status.roles and User.status.groups with kubectl --subresource=status.
5. Wait for the tak-operator to update /opt/tak/auth/UserAuthenticationFile.xml.
6. Wait two more seconds before testing a removal.
7. Use the XML event format from ../tak-server/tests/check-cot.py.
8. Send a presence event on each CoT connection.
9. Use a unique event UID for each routing check.
10. Observe each routing check for four seconds.
11. Restore each User's initial roles and groups in a finally block.

Temporary files held client keys with mode 0600 inside a private temporary directory.
The scripts removed those files when the tests ended.
No keys or session cookies are included in this record.

Interpretation and limits
- The tested HTTP session lost its admin permission after JNI reconciliation.
- Native group removal did not remove the existing CoT connection's group access.
- Reconnection removed access to the tested group.
- Certificate admission failed: unaccepted and retired certificates routed CoT.
- The tests did not identify the internal cause of the routing behavior.
- The tests did not check TLS session resumption, message storage, or authority expiry.
- Absence of a message applies only to the stated observation interval.
- The tests did not establish a maximum permission-removal delay.
- These failures prevent enforcement readiness. They do not block testing.
